# 企业微信 IP 白名单解决方案汇总

由于企业微信强制要求**发送消息的 IP** 必须在白名单中，而家庭/公司宽带通常是动态 IP，导致白名单频繁失效。以下是三种主流解决方案：

---

## 方案一：SSH 代理隧道 (当前方案)

**适合场景**：本地开发、调试。
**原理**：通过 SSH 隧道，让本地发出的请求 "借道" 云服务器的固定 IP 出去。

### 操作步骤
1. **启动代理**：
   ```bash
   # 您的服务器 SSH 端口是 10811
   ssh -p 10811 -D 1080 root@8.134.58.5 -N
   ```
2. **配置机器人**：在 `.env` 中添加 `NANOBOT__CHANNELS__WECOM__PROXY=socks://127.0.0.1:1080`。

**优点**：配置简单，无需改动服务器环境。
**缺点**：每次开发前需要手动运行 SSH 命令。

---

## 方案二：VS Code 远程开发 (Remote - SSH) 🌟 **推荐**

**适合场景**：长期开发、沉浸式编码。
**原理**：VS Code 直接连接到服务器，您的代码实际是**运行在服务器上**的，但操作界面在本地。

### 操作步骤
1. 在 VS Code 安装插件：**Remote - SSH**。
2. 点击左下角绿色图标 -> `Connect to Host` -> `Add New SSH Host`。
3. 输入命令：`ssh -p 10811 root@8.134.58.5`。
4. 连接成功后，在 VS Code 中打开服务器上的代码文件夹。
5. 直接运行 `npm run dev`。

**优点**：
- **完全解决 IP 问题**：代码就在服务器上跑，天然就是固定 IP。
- **环境一致**：不用担心本地和线上环境（Windows/Mac vs Linux）不一致。
- **无需代理**：不需要额外运行 SSH 代理命令。

---

## 方案三：直接部署到服务器 (Deploy)

**适合场景**：生产环境、24小时稳定运行。
**原理**：代码写好后，上传到服务器运行。

### 操作步骤
1. **上传代码**：
   ```bash
   # 使用 scp 上传 (需要输入密码)
   scp -P 10811 -r ./nanobot-ts root@8.134.58.5:/root/
   ```
2. **登录服务器**：
   ```bash
   ssh -p 10811 root@8.134.58.5
   ```
3. **安装并运行**：
   ```bash
   cd /root/nanobot-ts
   npm install
   npm run build
   npm run start
   ```

**优点**：最稳定，不用开电脑。
**缺点**：修改代码流程较长（修改->上传->重启）。

---

## 🔴 核心问题：SSH 登录失败

无论使用哪种方案（代理、远程开发、部署），**前提都是必须能登录 SSH**。

如果您遇到 `Permission denied`，说明**密码错误**。

**解决方法**：
1. 登录阿里云/腾讯云控制台。
2. 找到您的实例 -> **实例设置** -> **重置密码**。
3. 设置一个新密码，然后**重启实例**（部分云厂商需要重启生效）。
4. 使用新密码重试登录。
