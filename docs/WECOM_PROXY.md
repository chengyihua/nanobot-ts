# 企业微信 IP 白名单问题解决方案

## 为什么需要加白名单？

企业微信为了安全，要求调用 API (如发送消息) 的服务器 IP 必须在白名单中。

1. **接收消息 (Webhook)**：
   - 企业微信 -> 您的云服务器 (8.134.58.5) -> frp -> 本地电脑
   - 这一步没问题，因为是从外网发进来。

2. **发送消息 (API 调用)**：
   - 本地电脑 -> 企业微信服务器
   - 这一步是**直接连接**。企业微信看到的是您**本地电脑的公网 IP** (通常是家庭宽带动态 IP，如 `124.240.100.204`)。
   - 因为家庭宽带 IP 经常变动，所以您每次都要重新加白名单。

## 解决方案：使用 SSH 隧道作为代理

为了解决这个问题，我们可以让**发送消息**的流量也走云服务器，这样企业微信看到的 IP 就是固定的云服务器 IP (`8.134.58.5`)。

### 1. 建立 SSH 隧道 (SOCKS5 代理)

在本地终端运行以下命令（使用您的云服务器信息）：

```bash
# -D 1080: 在本地开启 1080 端口作为 SOCKS 代理
# -N: 不执行远程命令，只做端口转发
# -p 10811: 指定 SSH 端口
ssh -p 10811 -D 1080 root@8.134.58.5 -N
```

#### 💡 高级技巧：使用 sshpass 自动输入密码 (您已安装)

您可以使用 `sshpass` 来自动输入密码，避免每次手动输入：

```bash
# 将 '您的密码' 替换为实际密码
sshpass -p '您的密码' ssh -p 10811 -D 1080 -o StrictHostKeyChecking=no root@8.134.58.5 -N
```

#### 🔴 常见问题：连接超时 (Operation timed out)

如果出现 `ssh: connect to host ... port 22: Operation timed out`，说明**云服务器的安全组（防火墙）拦截了 22 端口**。

**解决方法**：
1. 登录云服务器控制台（如阿里云、腾讯云）。
2. 找到 **安全组 (Security Group)** 设置。
3. 添加一条 **入方向 (Inbound)** 规则：
   - **协议**: TCP
   - **端口**: 22
   - **授权对象 (Source)**: 0.0.0.0/0 (允许所有 IP) 或 您当前的公网 IP
4. 保存后，再次尝试上面的 ssh 命令。

### 2. 配置机器人使用代理 (已自动配置)

您的配置文件 `.env` 已更新，包含以下内容：

```bash
NANOBOT__CHANNELS__WECOM__PROXY=socks://127.0.0.1:1080
```

### 3. 重启机器人

SSH 连接成功后（终端会卡住不动，这是正常的），重启 nanobot：
```bash
npm run dev -- gateway
```
此时机器人发送消息将自动通过云服务器，您只需在企业微信后台白名单填入 `8.134.58.5` 即可。
