### Python 代码示例

```python
# 这是一个Python代码示例
class DataProcessor:
    def __init__(self, data):
        self.data = data
        self.processed = False
    
    def process(self):
        """处理数据"""
        result = [item * 2 for item in self.data]
        self.processed = True
        return result

# 使用示例
processor = DataProcessor([1, 2, 3, 4, 5])
print(processor.process())
```
